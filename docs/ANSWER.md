## A. Что сделано

Инвесторский лендинг заговорил с хаб-API и перестал утверждать то, что нельзя проверить.

1. **Слой данных (W1).** `src/api.js` — read-only клиент шести эндпоинтов (`/api/investors/report`, `/snapshots`, `/trend`, `/api/ecosystem/status`, `/api/read-model`, `/api/analytics/traffic`) плюс `/api/health`. Клиент не бросает исключений: любой сбой возвращает `{status: "unavailable", reason}`. Различаются `endpoint_not_deployed`, `timeout`, `network_error`, `http_error`, `not_json`, `unknown_endpoint`. Ответы с `source: "mock"` помечаются как demo.
2. **Реестр чисел (W1).** `src/numbers.js` — 26 записей: значение, единица, источник, `dataQuality`, `asOf`, флаг `demo`, происхождение (`config` | `brief` | `api`). `src/config.js` остаётся единственным источником параметров сделки; расхождение ловится тестом.
3. **Единый вход для цифр.** Компонент `Metric` печатает значение, бейдж `complete | partial | unavailable`, чип `DEMO DATA` и раскрываемый след (источник, `asOf` в UTC, формула, примечание). Отсутствующее значение — «—»; ноль — `$0`. Тот же компонент питает дашборд, счётчики, таблицу снапшотов и юридический блок.
4. **Экран состояния студии.** Новая секция `#status` читает `GET /api/ecosystem/status`, поддерживает словарь уровней L0–L4, игры, сервисы, подключения и причины. Пока эндпоинт не реализован (в текущей сборке хаба его нет), экран сообщает об этом прямо, публикует ожидаемую схему и показывает единственное известное число — готовность адаптеров из `read-model`, с качеством `unavailable`. Контракт оформлен как запрос к хабу: `docs/ECOSYSTEM_STATUS_API.md`.
5. **Снапшоты и выплаты.** Секция `#snapshots`: формула из брифа, календарь первого рабочего дня января/апреля/июля/октября (UTC), получатель = текущий владелец на снапшоте, по каждой строке — источник и ссылка на эндпоинт, нулевой квартал печатается как `$0` с объяснением. Прибыль за квартал хаб пока не публикует — колонки пула и выплаты честно показывают «—», и таблица включится без правок, когда поле появится.
6. **Юридический блок.** Секция `#compliance`: предмет сделки и риски, KYC/AML (провайдер не выбран), юрисдикции (не опубликованы), налоги, адрес программы mint и мультиподпись («в работе»), лимит на кошелёк из конфига, статус Terms и продажи, цели SLO с пометкой, что публичных отчётов пока нет.
7. **Лид и согласия.** Форма отправляет зафиксированный контракт `{email, language, source}` плюс `consents` (`investor-lead-v1`), пишет журнал согласий до отправки, даёт отозвать согласие и синхронизирует запись с сервисом согласий студии при заданном endpoint. Антиспам: honeypot, минимальное время заполнения, cooldown.
8. **Производительность и SEO (f-11).** Удалён блокирующий запрос к Google Fonts: шрифты объявлены через `local()` с системным fallback (операторский шаг — положить woff2 в `public/fonts/`). У изображений появились `width`/`height` и `decoding="async"`. `scripts/seo.mjs` добавляет `twitter:*`, абсолютные `og:image`/`twitter:image` и JSON-LD `Organization` + `Product`/`Offer` с `PreOrder`, пока продажа закрыта.
9. **Автоматические гейты.** `scripts/check-numbers.mjs` (AST-разбор копии: JSX-текст и строковые литералы), `check-secrets.mjs` (ключи, токены, seed-фразы, `.env`; в CI ещё и история git), `check-bundle.mjs` (JS < 200 kB gzip, CSS < 40 kB gzip). Всё включено в `npm test` и CI.
10. **Тесты.** 39 unit/render/client-тестов без браузера (математика и границы, реестр, SSR-рендер фикстур, реальный путь данных в jsdom) плюс браузерные спеки, включая новый `tests/browser/honest-data.spec.js` (бейджи, DEMO DATA, след источника, нулевой квартал, мёртвый хаб, журнал согласий, axe WCAG 2 A/AA).

## C. Как проверить

```bash
npm ci
npm test                           # 39 тестов + линтер чисел + скан секретов
npm run build && npm run test:bundle
node scripts/dev-hub.mjs &         # фикстура хаба (mock) на 127.0.0.1:5174
npm run dev                        # http://127.0.0.1:5173
npx playwright test                # 25 браузерных проверок (нужны бинарники)
```

Форма проверяется отдельным сервером («поле включено»):

```bash
VITE_FORM_ENDPOINT=/api/waitlist npm run dev -- --port 5175 &
TEST_FORM=1 TEST_URL=http://127.0.0.1:5175 npx playwright test tests/browser/form.spec.js
```

Что смотреть руками:

- Баннер под шапкой: состояние хаба и штамп «Данные обновлены» в UTC; при живом фикстуре — предупреждение о mock-режиме.
- `#status`: «эндпоинт отсутствует в текущей сборке хаба», ожидаемая схема, готовность адаптеров 0/5 с бейджем `unavailable`.
- `#snapshots`: формула, календарь (`2027-01-01`, `2027-04-01`, …), таблица с `$0` за квартал без прибыли и `$125` за квартал на $200,000.
- `#compliance`: «в работе» вместо адреса программы, пустые юрисдикции, предупреждения о рисках.
- Остановите фикстуру и перезагрузите страницу: числа, зависящие от хаба, станут «—», появится причина сбоя и кнопка повтора. Вчерашние значения не подставятся.
- Нажмите «ⓘ» у любой цифры: источник, `asOf` (UTC), формула.

Браузерные спеки требуют бинарников Playwright (`npx playwright install --with-deps chromium`) или переменной `CHROMIUM_PATH`, указывающей на уже распакованный Chromium. **Локальный прогон выполнен**: `tests/browser/honest-data.spec.js` — 9 проверок (включая axe) и `tests/browser/landing.spec.js` — 16 проверок прошли целиком; форма проверена отдельным сервером с `VITE_FORM_ENDPOINT=/api/waitlist` — 4 проверки отправки и трёх видов неуспеха. CI повторяет тот же прогон на каждом пуше.

## E. Границы, риски, честные оговорки

- **`/api/ecosystem/status` не существует** в текущей сборке хаба. Экран состояния работает как «ожидание контракта»: уровни не присваиваются, интеграции не додумываются.
- **Прибыли за квартал в хабе нет.** Поэтому таблица выплат не считает дивиденды из похожих полей: она показывает «—» и включится сама, когда появится `netProfit`.
- **Биржевые праздники не учтены** в календаре снапшотов. Правило сдвига даты должен утвердить оператор; выдуманная дата — выдуманное число.
- **Юридический текст — черновик**, квалификация NFT зависит от юрисдикции. Лендинг не утверждает, что NFT не является ценной бумагой.
- **Иллюстрации не являются прогнозом**: `$200,000 → $50,000 → $500/год → $125/квартал` подписано «не обещание» и посчитано той же формулой, что и таблица.
- **Журнал согласий клиентский.** Полноценный аудит требует серверного неизменяемого журнала — это задача оператора.
- **Проверено локально:** Playwright (25 + 4 прогона) и Lighthouse на финальной сборке. Оба инструмента требуют бинарника Chromium; в песочнице он подключался через `CHROMIUM_PATH`, CI ставит свои бинарники. Числа замеров зависят от машины: LCP 1.5–1.9 s, perf 0.97–0.99 на этой сборке.
- **`00_HUB_CONTRACT.md` отсутствует**, поэтому формат A–F реконструирован (см. оговорку в начале).
